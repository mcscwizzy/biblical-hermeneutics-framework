# Deprecated CKL archaeology compatibility records

This directory is retained only for stable legacy CKL IDs. It is not an
authoring source for archaeological evidence. New or corrected material
evidence belongs in the Archaeology subsystem (`archaeology_sites`,
`archaeology_items`, Scripture links, evidence details, and reviewed media).

The web compatibility endpoint redirects a matching legacy ID to the
authoritative archaeology item. Normal CKL browse/search and offline study
packs exclude these records, while Archaeology provides the dedicated browse,
detail, search, media, map, and offline experiences.

# UI-06 UX Change Report

## Before and after

The previous Companion overview placed Locations directly under Dig Deeper and mixed geography with the rest of the discovery preview. The revised overview keeps Explore the Narrative and adds one Places & Locations entry. Opening it shows passage-scoped Locations, Biblical Places, and Walk the Land in separate sections.

The desktop captures use Genesis 12:5–9. The focused view retains Maps identities, provenance, license details, and exact map actions. The 390 px capture shows the same view in the mobile Companion sheet without horizontal overflow.

## Browser checks

Firefox exercised the selected passage, Places & Locations entry, browser Back and Forward, chapter change from Genesis 12 to Genesis 13 while focused, mobile sheet opening, Back and Escape focus restoration, and 390 px horizontal overflow. The mobile capture is an exact 390 CSS px iframe viewport because the installed headless Firefox window has a 500 px minimum width.

# NE-11D2 performance and network

The real-data browser baseline counted requests over verse selection and complete journeys, not just activation: Genesis 7 Companion / 3 projection; Jonah 3 / 3; Matthew 3 / 3; Psalm 22 2 / 1; Deuteronomy 32 3 / 1. Individual verse selections cause refreshes. These single runs are not latency samples and do not establish duplicate or cancelled request counts, payload sizes, cache behavior, blocking, median or range.

The previous local NE-11D report measured Genesis preflight median 1.638 s, revalidation median 1.481 s, action-to-focus median 1.645 s, about 236 KB per projection and two projection requests before destination. Those measurements used two samples and are historical, not thresholds or a current comparison. No matched isolated NE-11C1 run was performed here. In particular, a successful Jonah Companion handoff did not exist there and cannot be compared as an equivalent journey.

Performance acceptance remains incomplete: collect at least three comparable cold and warm samples per primary journey and the requested negative passages, record response bytes and all phase timings, cancellations and request counts, and run equivalent Genesis scenarios at `628f7d13e35d77297586751f584c5a32c06d570d` in an isolated checkout. Preserve activation-time verification.

# Historical Vercel bundle investigations

These reports record package-size and preview measurements from earlier
Narrative Explorer releases. They predate the generated Commentary retirement
and current NE-9C/NE-10 state. Their measurements and recommendations are
historical; use the current [architecture](../../architecture.md),
[local development guide](../../local-development.md), and
[repository cleanup report](../../maintenance/repository-cleanup-report.md)
for current packaging boundaries.

The source reports remain as dated decision records. They are not CI gates and
do not define current Vercel or Docker inputs.

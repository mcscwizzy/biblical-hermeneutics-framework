# NE-11E4: First Corinthians retrieval

**Unresolved.** On the baseline, the full book-specific query test had three failing subtests and 63 passing subtests. A debug search shows that ranking uses aggregate keyword overlap plus a draft penalty; it does not generally measure whether matched words occur together in a passage-specific claim. For the weaker-members question, `ritual-purity-and-communal-holiness` scored 0.7055 and `1-corinthians` scored 0.6152. For the Corinthian meal question, the Pauline meal context scored 0.8907 and `1-corinthians` scored 0.8281. For the body-and-members question, the Pauline bodies context scored 0.8073 and `1-corinthians` scored 0.6883. Ordering also incorporates alignment, category, source and draft factors, so scores alone do not describe final ranking.

The records contain overlapping themes. In particular, the focused gifts record explicitly describes one body with many members; the broad book overview does not contain that exact expression. Neither the weaker-members question nor the body-and-members question names a book. A general rule that reliably makes the overview first while preserving more precise focused results has not been established. No book-specific ranking override, scholarship change, or assertion weakening has been made. The three failures remain a release blocker. Detailed ranked diagnostics are retained outside the repository.

The broader retrieval control batch found additional baseline failures with retrieval code unchanged: `CanonicalRetrievalTests::test_hybrid_retrieval_prioritizes_scripture_and_fuzzy_aliases`, and golden-query subtests for Joseph's bones, baptism and new creation, and temple symbol. The batch finished with 4 failures, 37 passes, and 11 passing subtests. These need investigation alongside the three First Corinthians failures; updating golden expectations without assessing relevance would not establish a correction.

A separate legacy hybrid retrieval defect was corrected: for a single-word lookup, a fuzzy person-name match now ranks ahead of incidental mentions, while exact identities remain first and multiword and Scripture searches retain their existing ordering. The original Abram regression and a focused identity control passed; the retrieval and precision batch finished with 26 passed and 4 passing subtests. This correction does not change the First Corinthians service ranking or repair the three golden-query failures. SQLite hybrid ranking has a separate implementation; its candidate collection now includes close person titles and aliases, and a focused SQLite regression plus a read-only existing-index check returned the expected person. The full SQLite storage suite passed 11 tests; the combined storage, legacy retrieval and precision batch passed 37 tests and 4 subtests.

# ED-6 Reader Discovery Pilot

ED-6 prepares a small, facilitator-led study of whether everyday Bible readers
can discover BHF research, describe contextual observations, follow the source
trail, and continue exploring. It does not evaluate a participant's beliefs or
theological conclusions.

## Read and run the pilot

1. Read the [baseline](baseline.md), [participant protocol](participant-protocol.md),
   and [consent and privacy script](consent-and-privacy.md).
2. Prepare the task assignments from the [task bank](study-task-bank.md).
3. Follow the [facilitator guide](facilitator-guide.md) and use the
   [notes template](participant-notes-template.md).
4. Ask the [post-session questions](post-session-questions.md), then apply the
   [measurement rubric](measurement-rubric.md).
5. Keep real records local. Use the [data management instructions](data-management.md)
   and [record schema](session-record.schema.json).
6. Keep the separate [scholarly review kickoff](scholarly-review-kickoff.md)
   independent of reader usability findings.

Readiness and current run limits are in [reader pilot readiness](reader-pilot-readiness.md),
[feedback analysis method](feedback-analysis-method.md), and
[validation results](validation-results.md). The [final report](final-report.md)
contains no participant findings unless genuine sessions have actually taken
place. The machine-readable phase ledger is [progress.json](progress.json).

6–8 consenting adults and schedules the first session. No participant records
were present in `.bhf-data/ed6-reader-pilot/` at the ED-6 baseline. The reader
study is therefore **AWAITING PARTICIPANTS**. The independent review queue
still requires qualified human review; automated checks and this study do not
approve scholarly claims.

For the first session, print the consent script and task cards, prepare a
private notes copy, assign the next unused anonymous code only after consent,
and use the participant's own mobile device where practical. The 390px browser
viewport is the acceptance-test setting, not a replacement for a participant's
natural device. Do not enter participant information into Git or an online
form.

# Participant Notes Template

Copy this template into the facilitator's private local notes. Do not commit a
completed copy to Git. Use only the anonymous participant code, such as P01.

## Session

- Participant code:
- Consent confirmed: yes / no
- Device class: desktop / mobile / tablet / unknown
- Optional study-experience band: regular / some / limited or none / prefer not to say / not asked
- Session status: complete / incomplete / stopped
- Quote consent: yes / no
- Assigned task IDs:
- Facilitator clarification(s), if any:

Do not record a name, email, church, denomination, IP address, or contact
details. If the participant stops, note only which tasks had actually begun.

## Repeat for each assigned task

- Task ID and passage:
- Task type:
- Completion: completed / partially completed / not completed / not attempted
- Assistance: none / minor prompt / substantial assistance / not observed
- Approximate duration in minutes:
- Source found: yes / partial / no / not applicable / not observed
- Claim connected to its source: yes / partial / no / not applicable / not observed
- Source locator found: yes / partial / no / not applicable / not observed
- Uncertainty or dispute notice recognized: yes / partial / no / not applicable / not observed
- Draft or human-review status recognized: yes / partial / no / not applicable / not observed
- Genuine follow-up question emerged: yes / no / unclear / not observed
- Observed problem category: critical integrity / accessibility barrier / navigation / terminology / evidence density / subjective preference / out of mission / other
- Direct observation (what happened):
- Confusing language (exact wording if useful):
- Facilitator interpretation (keep separate from observation):
- Participant quote, only with separate quote consent:

## Post-session responses

- “Was there anything you noticed or learned that made you want to explore the passage further?”
- “Which part of BHF was most confusing?”
- “What would you change?”
- Other direct observations:
- Facilitator interpretations:

Before importing, review every free-text field for direct or indirect
identifiers. Keep the original private notes under the same access controls as
the session dataset. The structured JSONL record does not contain the
facilitator's name or the participant's contact information.

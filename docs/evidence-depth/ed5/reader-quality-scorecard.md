# ED-5 reader quality scorecard

## Rubric

- **Discovery:** Pass when the current CKL service returns the exact expected
  record for the selected passage and its exact applicable anchor. This is a
  scripted projection criterion, not a measure of how quickly a person finds
  it.
- **Context:** Heuristic review checks whether source records keep textual
  observation, scholarly proposal, context, and qualification distinct where
  the record supplies them. A datum is not evidence that a reader understood
  that distinction.
- **Clarity:** The collapsed terminology guide is now available. Comprehension
  remains unmeasured until a reader explains the term in context.
- **Verification:** Script checks record-attached source IDs; existing reader
  contracts and ED-4 browser reports cover source detail disclosures. Current
  ED-5 live source-click completion was unavailable.
- **Continuity:** Pass for the scripted Jonah/Matthew route direction and
  support. Back/forward and focus restoration rely on inherited ED-4 browser
  evidence; ED-5 live browser execution is unavailable.
